# PepMAX — Design System Direction

## Brand direction
Modern, technical, biohack/biotech, commercial, precise, dark, high-contrast, laboratory-oriented.

## Typography
- Display / headings: Rajdhani
- Body: IBM Plex Sans
- Technical labels / SKUs / microcopy: IBM Plex Mono

Do not reintroduce rounded editorial/fashion display typography on the public storefront.

## Visual language
- dark navy/black base
- cyan/blue/violet accents
- technical grids and subtle glow
- strong whitespace and spacing hierarchy
- compact technical metadata
- product imagery presented cleanly and consistently

## Commercial patterns approved for adaptation
Reference: profoundaminos.com. Adapt patterns, do not clone identity, text, artwork, or proprietary layouts.

Approved patterns:
- announcement / trust bar
- navigation centered on catalog/shop/contact/cart
- strong hero with primary and secondary CTA
- featured-product sections
- catalog search and filtering
- product cards with variant selection
- quick-view pattern where useful
- clear Shop → Product → Cart progression
- visible trust/documentation signals only when supported by real evidence
- responsive commercial hierarchy

## Prohibited design/content patterns
- health/wellness framing
- therapeutic claims
- before/after or efficacy claims
- dosing, administration or reconstitution UI
- human/veterinary use framing
- unsupported purity/COA claims
- visual mimicry of competitor branding

## Localization
Public experience must be complete in EN / ES / PT, with Spanish as the default root experience and full navigation/content parity for English and Portuguese.
